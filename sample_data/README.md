# Bundled historical fallback data

Captured 2026-09-30T17:32:25.396004+00:00 from Coinbase Exchange public OHLC endpoints, without credentials. Each CSV contains a fixed snapshot of real historical exchange candles, not generated or live data. The app labels this source as bundled sample data and uses it only after both live providers fail. Market prices are venue-specific; USDT product candles are provided for the app’s BTC/USDT, ETH/USDT, and SOL/USDT selections.
